# SWITCH – Download

3D-Multiplayer-Partyspiel für 2–8 Spieler: Überlebe als Letzter in der schwebenden Arena und tausch mit **E** die Position mit einem anderen Spieler.

## ⬇️ Herunterladen

**[SWITCH für Windows herunterladen](https://github.com/thedarkzenitsu/switch-download/releases/latest/download/SWITCH-Windows.zip)** (ca. 115 MB)

Ohne Download direkt im Browser spielen: **https://switch-game.onrender.com**

## Installieren

1. Die Zip-Datei herunterladen.
2. Rechtsklick auf die Datei → **„Alle extrahieren“**. Nicht direkt aus der Zip starten!
3. Im entpackten Ordner `SWITCH` die Datei **SWITCH.exe** starten.
4. Windows warnt beim ersten Start („Der Computer wurde durch Windows geschützt“), weil die App nicht signiert ist → **„Weitere Informationen“** → **„Trotzdem ausführen“**.

## Spielen

- **Online spielen** – verbindet mit dem SWITCH-Server. Einer klickt im Spiel **CREATE LOBBY** und schickt den Raumcode, die anderen **JOIN LOBBY**.
  Ist der Server eingeschlafen, dauert der erste Start bis zu einer Minute.
- **Im WLAN hosten** – startet den Server auf deinem PC; Freunde im selben WLAN geben deine Adresse aus dem Fenstertitel ein.

| Taste | Aktion |
|---|---|
| WASD | Bewegen |
| Leertaste | Springen |
| Maus | Kamera |
| Linke Maustaste | Mitspieler als Ziel auswählen |
| E | SWITCH |
| ESC | Menü |
| F11 | Vollbild |
